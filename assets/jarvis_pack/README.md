# Imported Jarvis sound pack

These recordings were explicitly supplied by the repository owner from the local “Jarvis Sound Pack от Jarvis Desktop” pack for personal assistant use. They are not licensed under the application's MIT license. Original recordings are preserved for exact short responses; `reference.wav` is a short mono reference assembled from the supplied recordings for local voice conversion.

The application does not download this pack or include the full music recording from the original folder. Ultron mode applies a separate DSP profile; no original Ultron recording was supplied.
